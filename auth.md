# Authentication & Agent Access Instructions

## Overview

This site (`piotrunius.dev`) is a public personal portfolio and developer profile.

## Access Policy for AI Agents & Bots

- **Read Access**: All public portfolio information, projects, blog contents, and real-time status feeds are openly accessible without authentication.
- **Authentication**: No API keys, OAuth tokens, or login sessions are required to read site content or inspect public APIs.
- **Rate Limits**: Automated agents are requested to respect standard polite crawling rates (up to 30 requests per minute per IP on API worker endpoints).
- **Contact**: For inquiries, contact `contact@piotrunius.dev`.
